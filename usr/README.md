# MARC 21 Viewer

A Flutter application for parsing and viewing MARC 21 (MAchine-Readable Cataloging) bibliographic records. 

## Features
- Built-in parser for MARC 21 string data.
- Decodes the leader, directory, and variable data fields.
- Presents bibliographic records in a clean, readable format.
- Cross-platform support (Web, Desktop, Mobile).

## Tech Stack
- Framework: Flutter (Dart)
- UI: Material Design

## Getting Started

1. Ensure you have [Flutter](https://flutter.dev/docs/get-started/install) installed.
2. Clone the repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to start the application.
